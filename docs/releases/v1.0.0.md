# Forms API v1.0.0

The first release: a complete backend for dynamic forms, with versioned schemas, server-side validation,
autosave and querying by content on PostgreSQL `jsonb`.

## Highlights

- **Forms as data.** Nine field types, constraints, conditional visibility and requirements, and cross-field
  rules. Schemas are checked for consistency before they are stored.
- **Safe evolution.** Published versions are immutable, and submissions are pinned to their version. Every
  change between two versions is classified as breaking or not, and breaking changes are published only after
  explicit confirmation.
- **Autosave without lost input.** Drafts are always saved, the response shows what is still missing, and
  ETags stop two tabs from overwriting each other.
- **Fast queries.** GIN-indexed containment filters and keyset paging on UUIDv7 keys.
- **Ready to run.** `docker compose up`, OpenAPI with a Scalar UI, health checks, JSON logs, and a chiseled
  non-root image.

## Deutsch

Die erste Version: ein vollständiges Backend für dynamische Formulare mit versionierten Schemas, serverseitiger
Validierung, automatischem Speichern und Abfragen nach Inhalt auf PostgreSQL-`jsonb`.

- **Formulare als Daten:** neun Feldtypen, Regeln, bedingte Sichtbarkeit und Pflichtfelder sowie
  feldübergreifende Regeln. Schemas werden vor dem Speichern auf Stimmigkeit geprüft.
- **Sichere Weiterentwicklung:** Veröffentlichte Versionen sind unveränderlich, und Einreichungen sind an ihre
  Version gebunden. Jede Änderung wird als inkompatibel oder kompatibel eingestuft; inkompatible Änderungen werden
  nur nach ausdrücklicher Bestätigung veröffentlicht.
- **Automatisches Speichern ohne Datenverlust:** Entwürfe werden immer gespeichert, die Antwort zeigt, was noch
  fehlt, und ETags verhindern, dass sich zwei Tabs gegenseitig überschreiben.
- **Schnelle Abfragen:** Containment-Filter über einen GIN-Index und Keyset-Paging auf UUIDv7-Schlüsseln.
- **Sofort lauffähig:** `docker compose up`, OpenAPI mit Scalar-Oberfläche, Health Checks, JSON-Logs und ein
  „chiseled“ Image ohne Root-Rechte.

109 Unit-Tests, 52 Integrationstests gegen PostgreSQL 16 (Testcontainers) und ein End-to-End-Smoke-Test gegen
Docker Compose in der CI.
